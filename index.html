Aide / diagnostic

L’éditeur conserve ton code séparément. Le prototype affiche les diagnostics basiques de structure ; l’intégration d’un vrai analyseur Java côté navigateur nécessite une dépendance dédiée.

Suggestions

Le PDF prévoit des suggestions interactives pour les API Paper/Bukkit (par exemple Material). Cette interface prépare le champ d’édition mais ne prétend pas fournir une complétion Java complète sans moteur d’analyse.
